## Установка:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/KorotchenkoSV/frontend-project-12.git
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите приложение:
   ```bash
   npm start
   ```

4. Откройте [http://localhost:5001](http://localhost:5001)
